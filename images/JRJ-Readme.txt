Note:  These RX02 images have a "dummy" track 0 of all zeroes, and are 256,256 bytes long.  
So, you may want to remove the first 26*128 == 3328 bytes before using as an image file to load a floppy 
or with an emulator that only uses a floppy image with 76 tracks numbered 1-76 (252,928 bytes).
